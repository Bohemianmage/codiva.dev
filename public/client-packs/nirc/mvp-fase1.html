MVP Fase 1 - Workforce / personal eventual

Plataforma operativa con entrada dura (adhesión + alta IDSE aceptada), pool FCFS, check-in QR/geocerca, dispersión Stripe Connect, backoffice completo y deploy híbrido Vercel + Railway + Neon.

18 semanas · ~4.5 meses $980,000 MXN · solo desarrollo Proveedores / hosting aparte ~$571 / persona-día variable

Alcance incluido

  • Backoffice: vacantes, aplicaciones, pools, validaciones, convocatorias, eventos, finanzas, catálogos, RBAC
  • Pool + FCFS: score, auto-blast, aceptación, waitlist, no-show/reemplazo
  • Carga masiva: import CSV/Excel de candidatos/empleados
  • Operación: QR, geocerca, check-in/out, evidencias
  • Entrada dura: INE → contrato adhesión (Cincel) → alta IDSE aceptada → “Trabajando”
  • Salida: baja IDSE + Stripe Connect + asientos básicos + auditoría
  • Privacy: consentimientos, retención, jobs de disposal mínimos
  • Integraciones: IDSE PRO, Cincel, Stripe Connect, email/SMS

Fuera de Fase 1: EMA/EBA, face-match, WhatsApp masivo, Temporal cloud, app nativa, multi-país, CFDI automático al personal.
